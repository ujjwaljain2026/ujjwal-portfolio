# Ujjwal Jain — Developer Portfolio

A responsive dark React + Vite portfolio for a Java backend / full-stack internship search.

## Run locally
1. Install Node.js LTS from https://nodejs.org/ if it is not installed.
2. Extract this folder and open it in VS Code.
3. Open a terminal in this folder and run:
   ```bash
   npm install
   npm run dev
   ```
4. Open the localhost URL printed in the terminal (usually http://localhost:5173).

## Publish free with Vercel
1. Create/sign in to GitHub: https://github.com/ujjwaljain2026 and create a new repository, e.g. `ujjwal-portfolio`.
2. Upload/push this project folder to that repository. Do not upload `node_modules`.
3. Sign in at https://vercel.com/ using GitHub and choose **Add New → Project**.
4. Import `ujjwal-portfolio`. Vercel detects Vite automatically. Build command: `npm run build`; output directory: `dist`.
5. Click **Deploy**. Vercel will provide a public URL like `https://ujjwal-portfolio-....vercel.app`.
6. After future GitHub pushes, Vercel will rebuild and update the live site automatically.

Alternative: https://app.netlify.com/ can also deploy a Vite project; build command `npm run build`, publish directory `dist`.
